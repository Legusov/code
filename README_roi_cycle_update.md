# Обновление ROI-циклов

## Что изменено

`speed_hunter_trader.py` создаёт таблицу `roi_cycles`. Каждая запись хранит время старта цикла, его начальный баланс, статус, число раундов закрытия, время начала ROI-закрытия, а после завершения — время закрытия и зафиксированный баланс. Время хранится в Unix milliseconds (UTC).

При первом запуске с прежней базой добавляется одна запись текущего цикла. В качестве времени старта берётся `trader_state.updated_at` для `cycle_start_balance`. Исторические циклы до внедрения этой таблицы восстановить точно нельзя; такая миграционная запись помечается `start_source='legacy_state_timestamp'`.

Когда достигнут ROI-порог, бот получает фактические позиции Bybit и отправляет reduce-only market-заявки. Затем он ждёт, повторно получает список позиций и закрывает только те, которые ещё остались. Ошибка по одной заявке не мешает обработке остальных. После ограниченного числа раундов бот ещё раз проверяет позиции и сверяет их с SQLite. Если хотя бы одна позиция на бирже или в локальном журнале остаётся открытой, цикл остаётся в `CLOSING`, входы не разрешаются, а попытки продолжатся в следующем проходе бота.

Только после подтверждения, что все позиции закрыты и reconciled, бот фиксирует баланс, завершает старую запись цикла, начинает следующую запись, обнуляет банк убытков и устанавливает 5-минутный запрет на новые входы. Срок паузы хранится в `trader_state`, поэтому перезапуск процесса её не сбросит.

## Параметры

| Переменная окружения | Значение по умолчанию | Назначение |
|---|---:|---|
| `ROI_CLOSE_RETRY_ROUNDS` | `3` | Число раундов закрытия в одном проходе |
| `ROI_CLOSE_RETRY_DELAY_SECONDS` | `3` | Интервал между раундами и перед финальной проверкой |
| `ROI_POST_CLOSE_PAUSE_SECONDS` | `300` | Пауза до разрешения новых входов после завершённого ROI-цикла |

Если позиции остаются открыты после трёх раундов, бот сохраняет состояние `roi_close_pending=1`, ждёт обычный период `POLL_SECONDS` и затем продолжает закрытие.

## Запуск проверок

```bash
python -m unittest -v test_roi_cycles.py
python -m py_compile speed_hunter_trader.py test_roi_cycles.py
```

Тесты используют подмены Bybit API и не подключаются к реальному аккаунту.
